## 1. 先给结论

本轮不是推倒重做，也不是把四张效果图贴进小程序。目标是在现有业务与组件上，用低饱和栏目底色、统一图标、精简信息层级和适量横幅，把“今天 / 规划 / 机会 / 我的”做成同一品牌下的四种不同工作场景。

本蓝图把用户提供的三份 Markdown 及素材 ZIP 当作设计与验收依据，并结合当前分支源码确定施工次序。若文件里的示意图与现有业务能力冲突，以真实业务与权限为准。

## 3. 已确定的视觉规则

### 3.1 色板

| 语义 | 色值 | 用法 |
|---|---|---|
| 页面基底 | #F6F4F0 | 暖纸灰，不大面积纯白 |
| 品牌深蓝 | #174E78 | 顶部、品牌入口、主要操作 |
| 深蓝文字 | #123D63 | 标题和必要强调 |
| 交互蓝 | #2A6B92 | 链接、选中态 |
| 柔金 | #CEA460 | 少量点缀，不给每张卡描金边 |
| 课表 | #E7F1F7 | 今天页课表栏目 |
| 规划 | #F7ECDE | 今天页阶段规划栏目 |
| 快捷入口 | #E8F2EC | 今天页常用入口区域 |
| 资讯/记录 | #F1F4F7 | 信息密集的列表区域 |
| 服务/帮助 | #F5EEE3 | 小范围帮助模块 |
| 卡片 | #FFFEFC | 具体内容面板 |
| 主文字 | #1B3D54 | 标题与正文 |
| 次文字 | #65798B | 辅助说明，保证可读性 |

颜色应用在栏目容器，不是给每个卡片单独随机上色。四页同属一个体系，但不强制使用相同布局。

### 3.2 版式规则

- 页面横向边距约 24–28rpx；栏目内边距约 20–24rpx；相邻模块约 14–20rpx。
- 圆角以 12–18rpx 为起点，具体以真机观感调整；避免过度圆润、厚重阴影和每卡金色顶边。
- 标题、状态、主操作的层级明确。重要正文不能依赖浅色区分。
- 横幅只做视觉背景；日期、学期、姓名、按钮、课程和状态必须由原生文本/真实数据动态渲染。
- 不新增 UI 组件库，不为视觉统一重刷 21 个页面，不改 app.wxss 全局样式。
- 不增加假通知、假任务进度、假剩余评估次数、假老师、假学校图片或假资讯截止标签。

## 4. 四页目标构图与功能契约

### 4.1 今天

目标顺序：紧凑日期/品牌区 → 课表 → 阶段规划摘要 → 常用入口 → 低频品牌/帮助。

- 顶部用 today-campus-hero.webp 做低矮品牌横幅，建议 150–180rpx 的初始高度；真实日期与当前可用阶段信息叠加在左侧，不重复堆叠“今天”。
- 课表区用淡雾蓝底；保留今天/明天切换、本周课表入口、真实课程顺序、地点和“下一节”逻辑。
- 课表加载失败、未导入、当前阶段无课表、当天无课分别沿用现有状态，不把错误伪装成无课。
- 阶段规划用淡米金底，继续显示真实阶段摘要和四类计划状态；没有日任务模型，不显示完成百分比或虚构日任务。
- 快捷入口顺序为 AI 评估 → 院校库 → 保研资讯 → 倒数日。四个入口形成 2×2；倒数日放在右下位置，保留现有本机开关与数据。联系客服作为独立、易点击的横向入口，不与倒数日混为同一功能。
- 低频“服务介绍 / 关于九辰 / 官网”保留在下方，不能挤压课表与规划。

### 4.2 规划

目标顺序：页面标题与真实学生工具 → 折叠学期选择 → 当前浏览阶段摘要 → 四类计划 → 老师关系 → 辅导记录。

- 使用 semester-books-banner.webp 作为轻暖横幅装饰；学期文本与状态保持动态。
- 继续区分“档案当前阶段”和“正在查看阶段”，保留折叠/展开、切换、返回、课表导入、本周课表入口。
- 四类计划以简洁条目/面板组织，强调真实状态和下一步操作；不恢复占用手机宽度的纵向侧栏。
- 老师姓名、主辅导/协助关系必须来自真实关系数据。主辅导与协助是关系类型标签，不应自行扩写成权限或职责承诺。
- 保留旧待审记录兼容、老师权限和计划保存规则；本轮不改 TS 业务逻辑、API、数据库或权限。

### 4.3 机会

目标顺序：简洁标题 → 院校库主入口 → 分类 → 精选/最新资讯 → 次级收藏与即将退出列表。

- 使用 school-library-hero.webp 只装饰院校库入口，不得标为某所具体大学。
- 资讯标题、来源、发布时间和分类优先，封面缩小为辅助；图片加载失败仍有自然回退。
- 收藏和即将退出列表不能删除。将其移到主资讯流之后，或以已有可用交互收纳为次级区；不新增后端字段或状态。
- “从资讯列表退场”不等于“报名截止”。没有可靠截止日期的文章不显示“即将截止/已结束”。
- 管理员待分类提示继续按角色显示；错误、空列表和待分类状态保持真实。

### 4.4 我的

目标顺序：个人品牌头部 → 成长档案/AI 历史/收藏/客服 → 账号与身份设置 → 官网/帮助。

- 使用 profile-calm-campus.webp 作轻量头部背景，姓名与身份由真实数据覆盖显示。
- 内部编号压缩为清楚、可复制的次级信息，避免在个人页占据首屏主要视觉权重；不可取消编号查看或复制能力。
- 成长档案、AI 评估历史与草稿、收藏、客服是常用入口。
- 客服与专属老师明确区分。无真实老师关系时不显示虚构的专属老师入口。
- 账号切换、解绑、退出、注销放在较低频设置区；保持现有权限校验、二次确认和错误提示。
- 管理员兼任身份与老师页面使用同一页面的情况需要回归；不能把“学生视觉精简”做成其他角色入口丢失。
