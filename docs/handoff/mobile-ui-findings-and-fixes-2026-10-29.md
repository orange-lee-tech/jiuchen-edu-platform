- 新增 3 项静态／引用回归断言至 `tools/testing/miniprogram-navigation.test.cjs`。

## 仍需要单独做的业务层收口

1. **真实当前学期**：今天页显示的学期来自服务端 `students.currentStage`；规划页“正在查看”仅切换视图，不能更改档案当前阶段。若原始档案默认为大一上，必须通过经授权的资料更新或最小 API 增加真实学期设置，不能在 UI 本机伪造。
2. **老师正式姓名**：管理员兼任老师可通过“我的”绑定已有合法内部编号，但教师正式档案姓名 `teachers.name` 与用户 `users.displayName` 不同。当前只有用户显示名编辑接口，不能把昵称无核实地当作正式姓名。建议单独设计管理员授权的更名操作和审计记录，不擅自改变生产数据。
3. **倒数日云同步**：本轮是可用的轻量本地版本；未来跨设备同步需单独的数据与权限设计。
4. **已登录管理员兼任角色绑定**：`/me/identities/bind` 仅允许满足既有资格的、未认领且可自助领取的学员/老师编号；管理员列表中“绑定游客账号”流程只接受普通未绑定账号。两条流程不能混为一谈。
