## 微信体验版一次性验收

1. 本人本地执行 `git pull --ff-only origin p1/foundation`，用 `git rev-parse HEAD` 核对获准的候选 SHA。在微信开发者工具选择 `apps/miniprogram`，编译检查，不要上传整条仓库为生产 API。体验版上传、版本号和发布时间由本人操作；不得正式发布。
2. 用真实学员分别从院校详情和成功 AI 评估结果联系顾问。确认弹窗后检查剪贴板模板及空值，手动粘贴到企业微信客服；测试取消、复制失败、账号切换不会发送旧身份。已验收的基础客服联通无需重做。
3. 从新完成的报告和历史重开的报告分别保存摘要图与完整长图，在相册核对全部章节、边界、姓名/UID/日期、全长 −25° 水印；检查拒绝相册权限时没有成功提示。不要公开带个人资料的原图。
4. 管理员切换周／月／年及折线／柱状，核对已有真实成功评估与账号记录数分别来自评估 API 和 `/me/admin/users`；支付、账本缺表显示来源不可用。身份页核对未认领、已认领未分配、已分配与老师实际负责人数；缺真实样本则记 PENDING。
5. 学员资讯检查头条和列表日期、分类、空态、未分类隔离及详情。由于生产 News V2 关闭，公众号原文收藏只显示“待开放”，不得宣称保存成功；管理员核对最新真实文章与同步回执。院校地图仅做受影响页面回归，不重导入已有 172 张图片。
