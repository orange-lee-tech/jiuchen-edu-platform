固定前端 `283aaf15fc0047f100028eee547a5581c3f8c047`，固定 API `1b8ae8b3c5a1285b84ab6b5f573ca9db5d93d0a7`。上传微信体验版前记录实际后端 active SHA 与开关；如果尚是 8cc4，先验证旧链路兼容，新 API 依赖项填 BLOCKED，切流后只重测受影响的关键链路。现场准备游客、新学员、旧学员、真实老师（含已分配及未分配）、管理员的可用账号；至少一台 iOS 与一台 Android，记录微信/系统版本。账号和个人资料不进 Git。
