1. **AI 服务管理**：预设约十家常用中国大陆 API 平台（阿里云百炼/千问、DeepSeek、月之暗面/Kimi、火山方舟/豆包、腾讯云混元、百度千帆、智谱、MiniMax、讯飞星火、百川等），按平台切换*文本*模型列表；以经官方核实的**型号/版本/API 精确模型 ID**为主、用途备注为辅；不能把市场宣传产品名当 API 接口。按地域与平台预填可见、可修改的 HTTPS Base URL，填写 API Key；存在 Endpoint ID/地域/能力差异时明示。未核实的模型标注待验证，绝不伪造兼容性。

## 权限与全局生效
- **保留双 PIN**：创建对象设独立六位 PIN；首个对象自动生效；之后新候选保存但不启用；切换必须校验当前生效对象控制 PIN + 目标对象 PIN，可设成同一个数值。错误或并发版本冲突不得切换，草稿不生效。已有业务控制盒审计/锁定逻辑不可偷偷删除。次数方案按既有双 PIN/全局版本机制管理。
- 服务器加密保存 AI Key，读取接口不回显明文，密钥不入 Git/日志；管理员保存、测试、启用都能在手机完成。
- 全局唯一现役配置由后端按请求读取或版本一致缓存；切换确认后所有**新开始**的用户 AI 评估使用新配置，无需重启 ECS。切换前已启动任务允许完成旧配置。连接测试不能只测 HTTP 200，要验证九辰评估报告可解析、能落库；失败保持现役。密钥测试与真实评估的费用提示明确。
