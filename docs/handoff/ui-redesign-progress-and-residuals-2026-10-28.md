## 4. 视觉一致性审计发现

当前分支更改了全局 `app.wxss`，但大量页面有独立背景、卡片、字号和圆角定义，会覆盖全局视觉规则。以下页面的 WXML/WXSS 未在本轮首批 UI diff 中修改：

- 学业定位：`pages/position`
- 成长履历：`pages/growth-profile`
- AI 评估输入、历史、结果：`pages/assessment-form`、`pages/assessment-history`、`pages/assessment-result`
- 个人资料编辑：`pages/profile-edit`
- 院校资料库：`pages/library`
- 管理员工作台：`pages/admin`
- 登录、产品／详情及其他稳定子页。

部分页面仍有独立页面背景、卡片底色、局部配色和版式。例如 `growth-profile.wxss`、`assessment-form.wxss` 使用自己的页面背景与蓝色定义；`admin.wxss` 保留独立的深蓝／金色头部与卡片定义。它们不一定各自构成功能缺陷，但必须在统一视觉审查中确认层级、颜色语义、密度、圆角与小屏表现。

**已处理的设计规范冲突：** 设计系统与体验蓝图已同步记录当前分支的暖中性色、蓝色主操作与少量金色强调。共享全局组件已收敛到克制圆角；本轮又扫描了全部 21 个页面 WXSS，将识别到的结构卡片／操作按钮／输入框／底部弹层圆角分别收敛到 8rpx／8rpx／6rpx／10rpx，保留语义状态胶囊与圆形时间点。局部背景、配色、层级和页面布局仍需逐页审查，不能把圆角统一误当作整体视觉已统一。
