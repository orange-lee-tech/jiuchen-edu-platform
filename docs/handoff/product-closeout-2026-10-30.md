# 产品功能收束候选（2026-10-30）

本地候选不代表生产或真机验收。生产 API 以现场回执为准，本轮不执行生产操作。

- 评估草稿独立使用有长度和数量限制的宽松校验；正式运行前仍执行完整输入及账户学业资料校验。草稿不进入模型或额度预留流程。
- 首页近期任务读取真实截止日期，区分空结果与错误；点击后定位对应计划中的任务。此前生产读取失败的具体请求和状态码仍待现场核对，不能断言历史根因已解决。
- AI 收支台账的人工余额快照为追加记录，保留账户对象、币种、核验时间、操作者、阈值和备注。调用成本以调用绑定的已审核价格版本与供应商返回用量估算；价格或用量缺失、核验当分钟或跨快照运行中请求、峰段价格待核对时不提供确定的预计余额。估算按单个服务对象统计，其他对象可能共享同一供应商账户，必须核对供应商账单；不等同实时余额或实际账单。
- 教师个人待办由服务端持久化并按活跃教师隔离。学员汇总的各项查询均限制在当前有效分配范围内；计划详情及课表沿用现有学员工作区。未绑定账号时 AI、购买和次数显示不可读取。

新增 API：`GET/POST /me/admin/ai-balance-snapshots`、`GET/POST /me/teacher/todos`、`PUT/DELETE /me/teacher/todos/:id`、`GET /me/teacher/students/:id/summary`。管理员快照写入不允许只读身份；教师接口只允许活跃教师本人。

新增迁移：`db:upgrade:ai-balance-snapshots`、`db:upgrade:teacher-todos`；均为新增表，不删除旧数据。仅在独立 MySQL 8 合成库中演练，生产迁移和候选 API 发布需要后续单独授权。旧 API 回滚时新表应保留，不能反向删除业务记录。

仍需负责人在微信开发者工具与真实手机核对草稿恢复与正式提交、人工余额和权限、教师双账号隔离、近期任务错误与跨页定位；不发起真实付费模型调用或真实支付以冒充本轮自动化测试。
