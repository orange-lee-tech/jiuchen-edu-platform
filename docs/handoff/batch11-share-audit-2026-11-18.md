# Batch 11 分享接线与验收边界（2026-11-18）

- `app.json` 注册主包 24 页、分包 3 页，共 27 页。27 页均有好友和朋友圈回调；公共工具在每页 `onShow` 启用好友及朋友圈菜单，并在 `onHide`、`onUnload` 注销复制链接监听。首页与品牌页保留各自原有分享标题和封面。
- 默认好友分享指向当前静态页面。资讯、产品、院校详情仅在对应数据读取成功且公开 ID 符合白名单时携带 ID；未准备好时分享首页。朋友圈不指定路径，仅对这三类公开详情返回白名单 query。评估结果好友分享指向评估历史，规划编辑指向规划页，只读代看指向首页。其他私有 ID、登录参数和未知参数一律不进入分享回调。
- `wx.onCopyUrl` 只返回白名单 query，离开页面调用 `wx.offCopyUrl()`。私有评估结果、规划编辑、只读代看页面收到无参数复制链接时分别转到评估历史、规划页、首页；目标页仍按原有鉴权执行。原生菜单是否显示“复制链接”、粘贴结果及接收方打开能力受微信客户端控制，仍需真机逐页验收。
- 微信开发者工具 `build-npm --project apps/miniprogram` 两次在退出码 0 时输出 `__NO_NODE_MODULES__`，一次使用临时目录联接，一次使用临时实体依赖目录；两者均按失败记录。临时目录已移除，原有 `project.config.json` 未纳入提交。仓库小程序没有 `build` npm script；TypeScript 检查及本地自动化测试另行执行。
- 本轮没有微信上传、预览发布、ECS 部署或生产数据操作。朋友圈单页模式、复制链接菜单及登录限制须由人类开发者在目标客户端和接收方真机核验。
