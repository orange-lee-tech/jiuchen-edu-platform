# 资源成本防火墙（设计，未施工）

目标是限制小程序调用 AI 评估、课表图片识别等可能产生变动费用的服务。此文只固化原则，不创建表、不修改生产计费配置，也不把估计费用写成平台账单。

## 调用前预算

服务端按可信用户和功能检查身份、免费／付费额度、频率、并发、文件大小及当日全局预算；超限在调用外部供应商前拒绝。预算以配置的上限和保守单次估算做准入，不信任小程序上报的 token、图片成本或价格。精确阈值和异常放行机制需独立审批。

## 调用中记录

每次外部调用关联不可泄露个人信息的请求 ID、功能、供应商、模型、开始／结束时间、成功失败及供应商返回的用量字段。识别重试与同一业务任务，避免重复计入；日志不保存完整简历、图片、密钥或个人资料。现有数据没有逐次成本时应显示“未记录”。

## 调用后校准

定期用供应商账单／用量 API 与服务端调用记录对账，再与公司实际支付凭证核对；平台账单才是费用依据，令牌数或请求次数仅用于预警估算。比较预算、实耗、失败与重试，调整上限；余额过低或账单异常时告警与停止新调用的条件须先演练。上线前另行确认数据来源、权限、保留期、误差与回滚，不以本设计授权生产改动。
