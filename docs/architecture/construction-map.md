# 九辰教育平台施工地图

> 更新时间：2026-09-20  
> 本文是当前工程状态的唯一高层施工地图。它回答三个问题：现在做到哪里、哪些已经验证、下一步按什么顺序施工。

## 1. 当前结论

项目已经越过“只有骨架”的阶段，进入 **P1 收口 + P2/P3 局部并行施工**。

当前已经具备：
- 原生微信小程序五主入口页面骨架；
- Fastify 单体 API；
- Vue 内部管理后台；
- Test MySQL；
- 微信登录/服务端会话/游客身份基础实现；
- 学员、老师、管理员内部ID模型；
- 学员课堂阶段规则与最小后台编辑能力；
- 九辰教育服务号官方发布接口读取能力；
- 服务号资讯入库与小程序资讯读取代码框架；
- 集中测试清单与 GitHub CI。

当前仍不能称为“V1 可发布”，因为登录身份链、权限边界、课堂真实数据、AI 评估、支付、生产部署和完整回归尚未完成。

## 3. 当前已确认外部系统

### 微信小程序
- AppID 已配置到本地服务端；
- 微信开发者工具/体验版流程已走通；
- 生产前仍需完成正式隐私、域名、支付等平台配置。

### 九辰教育微信服务号
- 服务号 AppID / AppSecret 已由服务端读取；
- 官方 access_token 获取已验证；
- `freepublish/batchget` 已验证可读取九辰真实已发布文章；
- 本地公网 IP 动态变化，因此只适合作为临时联调源；
- Production 同步应从固定公网出口 IP 发起。

### 公司门户网站
现有官网仓库：`orange-lee-tech/startup-company-website`。

已确认现网为：
- Next.js 静态导出 `out/`；
- 公网 80/443 由 Nginx Proxy Manager 处理；
- 宿主机 Nginx 8088 提供静态站点；
- 源码目录 `/www/wwwroot/startup-company-website`；
- 官网不依赖长期 Node 进程。

这意味着小程序 API 可以与官网共用同一阿里云主机，但必须作为独立运行单元部署，不能混进官网静态目录或共用进程生命周期。

## 4. 开发阶段重新解释

### P0 奠基
**状态：基本完成**

产品基线、宪法、领域模型、架构边界已建立。

### P1 基础链路
**状态：代码基本完成，人工验收未完成**

重点剩余：
- 微信首次/再次登录；
- 游客身份；
- 退出/注销；
- 内部ID认领；
- 管理员绑定；
- 角色权限隔离。

### P2 原型主体页面
**状态：进行中**

五主入口已有可运行页面，但距离外部参考原型的信息密度与细节仍有明显差距。

### P3 我的课堂与运营后台
**状态：进行中**

阶段规则、课堂 API、后台计划编辑、老师授权关系、辅导记录持久化与后台录入已具备第一版；真实课程级 GPA 字段、更多计划详情和完整人工验收仍待建设/验证。

### P4 AI 保研评估
**状态：基础接口施工中**

已开始完成 Assessment 输入/输出 Schema、Evidence Schema、历史持久化、Draft/Run API、Retriever / Provider Adapter。当前不接假模型，Provider 未配置时明确返回不可用。Case Schema 等真实案例预处理结果后再冻结。默认采用“检索增强 + 大模型推理”，不默认训练自有大模型。

### P5 评估额度与支付
**状态：未施工**

免费额度、CreditLedger、微信支付、回调幂等均尚未实现。

### P6 Production 与收尾
**状态：未施工**

包括阿里云部署、固定出口 IP、域名、TLS、监控、备份、审计、隐私、完整回归和微信审核。

## 5. 下一阶段优先级

当前集中测试债务允许后移，不要求为了多设备账号或动态公网 IP 阻断主体开发。

接下来按以下顺序推进：

1. 保持 CI 全绿；
2. 收敛登录为微信一键登录 + 微信手机号快速验证，优先使用微信官方能力；
3. 把课堂真实业务字段与后台操作继续补齐；
4. 获取并清洗可用于 AI 的院校/项目/案例数据；
5. 冻结 AI Assessment 输入/输出 Schema；
6. 做 AI 最小闭环；
7. 再做额度/支付；
8. 在适合的多人/多设备测试窗口集中偿还 AUTH / ID / ADMIN / 资讯真机测试债务；
9. 最后迁移到 Production 阿里云拓扑并做完整回归。

服务号资讯本地同步不再反复追逐动态公网 IP；现阶段保留已验证的官方读取事实和待测入库链，Production 使用固定出口 IP 后再集中复测。

## 6. 红线

- 不因为附件原型存在固定评分公式就恢复固定五维评分；
- 不把外部案例宣传成九辰成功案例；
- 不让小程序直接持有 AI Key / AppSecret / DB 凭据；
- 不让生产 API 与官网共享同一进程、目录、环境变量或发布脚本；
- 不在同一服务器上通过“一个 npm start 管所有东西”的方式运行；
- 不在身份与支付未验证前公开发布；
- 不用本地动态公网 IP 承担生产服务号同步；
- 不建立账号密码体系或自建短信登录来替代微信已有官方认证能力；
- 微信生态能力施工前先查官方组件/API与权限条件，避免闭门造车。
