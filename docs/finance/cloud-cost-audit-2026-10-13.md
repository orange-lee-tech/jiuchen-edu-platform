# 九辰教育云资源经济账与防超支审计（2026-10-13）

> 状态：DOCUMENTED / 成本审计，不是采购、迁移、部署、DDL、计费开关修改授权。依据用户于 2026-10-13 提供的腾讯云控制台截图、仓库 `docs/handoff/CURRENT.md`、`docs/ops/ecs-resource-map.md`、`CONSTITUTION.md`、`docs/product/credit-payment-contract.md` 及此前真实评估测试回执。金额严格区分「已付」、「公开报价」、「测算」、「未核实」。此文不保存账号ID、密钥、订单号、个人信息。

## 1. 结论及口径
1. 阿里云 ECS **确实持续产生费用**，兼容承载官网与小程序 API；复用意味着「不额外采购一台小程序服务器」，**不是 ECS 成本为零**。续费/历史实际支付金额未从截图获得，标记 UNKNOWN。
2. 腾讯 CloudBase `cloud1`（上海）现有套餐「微信体验版」，截图到期日 2027-03-17 23:59:59；购买页「个人版当前版本」或可升级个人版的界面文字不能覆盖环境列表给出的现状，**必须以实际环境套餐/账单为准**。正式发布后是否改变到期规则须再次核腾讯现行政策。
3. 腾讯 OCR 后付费：用户表示**未开通**；已见部分接口「未开通」，未核验所有接口，禁止推断任何接口都永不扣费。
4. 本次观察账单报表为 ¥0.00，非全年成本零。相较高阶版的差价是**潜在避免支出**，不可记为已实现现金节省。
5. 小程序商业充值/支付生产缺表（见 CURRENT），不是已实现收入。

## 2. 实际架构与归集边界
| 资源 | 用途 | 事实与状态 | 计费责任 |
|---|---|---|---|
| 阿里云 ECS（Alibaba Cloud Linux 3，2 vCPU，约1.8GiB RAM，40G盘） | 官网 jiuchenedu.com + 小程序 API、后台任务、静态资源等 | 已部署；官网与 API 隔离，API MemoryMax=256MiB，CPUQuota=50%；主机此前使用18G，可用20G，时点快照 | **已有持续支出**：实例、云盘、公网带宽/流量、快照/备份、续费均须查实际订单；官网、小程序按约定分摊；不可双算 |
| 腾讯云 CloudBase | 小程序生产 MySQL 数据、存储及相关云能力 | `cloud1` 上海微信体验版，截图到期 2027-03-17；真实数据库仍远端，不得误报「已迁到 ECS」 | 当前已展示套餐/历史计费为0；未来企业套餐、可能超额费用待核 |
| 腾讯 OCR | 文档、表格、图片解析 | 45个资源包名义44050单位，其中消耗13；各包接口不同，不能合并为可通用44050页 | 现有免费包抵扣；后付费状态需逐接口核实 |
| 阿里云百炼 qwen3.8-flash | AI 评估模型 API | ECS API 调用，不是 CloudBase AI；历史真实 Benchmark 完成 | 按 Token 计价：须用阿里云账单核总量 |
| 微信官方能力 | 登录、客服、支付（尚未上线）等 | 按已验收和待验收区分 | 商户手续费/其他收费待核；不伪报已支付或已收款 |

**官网分摊示意**：令 ECS 年实际支付金额为 E，分摊给小程序比例 a（依据 CPU/网络/服务占用或企业财务约定），则官网成本 E×(1-a)，小程序 ECS 分摊 E×a，总额仍为 E。企业整体年度总成本不得再把两份 E 相加；**增量经济成本**则重点判断因上线小程序而是否引起 ECS 升配、带宽或运维增费。

## 5. AI / OCR 变动成本的可重算模型
- AI 原始实测两组 Token：（输入2759，输出1124）；（输入2864，输出1416）。按历史讨论的输入¥0.8/百万、输出¥2.7/百万举例：单次分别 ¥0.0052392 / ¥0.0061136，均值¥0.0056764。**这不是经当日阿里云账单核对的当前单价**，实际含额外请求/重试/缓存变化。
- OCR 文档多模态假设单价 ¥0.08/页，按页计、不是每文件计。1000页/月＝¥80/月；若免费包到期不可每月重复减1000页。接口适配、计费失败请求、预付费折扣另核。
- 示例统一预算：AI每月1000次、OCR每月1000页，年AI约¥68.12，年OCR约¥960；CloudBase个人/标准原价/企业版各+¥238.8/¥2388/¥11988，分别为年¥1266.92/¥3416.12/¥13016.12，**均未含ECS既有租金、额外云存储及流量、微信支付、税费、人工和备份成本**，不是可对外承诺的「公司全年云总开销」。
- **公司全年云成本公式**：实际 ECS 年账单 E + 实际 CloudBase 年账单 C + 百炼实际年调用 A + OCR实际年账单 O + 其他云产品与带宽/备份真实账单 X；将ECS分摊只是内部成本核算，不额外增加总额。
- 已有商业拟定学员免费评估5次、游客1次、付费一次¥1.9/10次¥16.9；但 CREDIT_ENFORCEMENT_ENABLED 和真实支付 Schema/回调生产状态不得假设已开启，见 CURRENT / credit-payment-contract。

## 6. 成本治理建议（未执行）
1. **AI 评估**：服务端唯一用户标识+游客识别，免费赠送版本幂等、额度预占与完成扣减、运行中拒绝重复、合理并发/重试上限；按用户/平台日月预算监控，并在超限前拒绝调用上游。模型失败仍可能有实际 API 成本，用户额度返还不等于上游退款。
2. **OCR**：限制每人每天/每月页数、单次上传页数/字节/格式、失败去重哈希、实际请求量计数；初始建议日3页/月20页，平台暂设月预算¥100，80%报警、100%阻断。仅为提案；按活跃用户和真实账单调整；超额后提供手填课表/资料的降级路径。
3. **腾讯云**：云开发新购页「超限按量」默认勾选风险；必须检查实际环境的开关、账单告警和扣费规则，未批准不得开启；OCR各接口后付费单独核。不可将「设置了告警」当作资金硬封顶。
4. **备份**：保留 CloudBase真实数据源的可恢复逻辑备份，异地加密存储、周期恢复演练、密钥与权限交接；ECS官网、API配置/数据和DB备份分别列入。当前未完成恢复验证，不称安全合格。
5. **企业移交**：核定账号归属、支付主体与账单、企业实名限制、MySQL环境数据导入导出、月度预算、故障SOP；避免依赖开发者个人账号和设备。
