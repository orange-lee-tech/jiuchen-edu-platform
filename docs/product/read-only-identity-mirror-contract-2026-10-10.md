**状态：GitHub 已施工 / 生产未部署 / 微信真机 NOT RUN。**

## 权限表

| 当前登录主体 | 允许查看的镜像 | 禁止 |
|--|--|--|
| student/user | 无跨身份镜像 | 不能传别人ID读取私域内容 |
| teacher | 自己在 assignment 表真实绑定的所有学生，不管哪个学年 | 别的学生/老师，不得在镜像编辑、审批、导入、AI运行、扣次 |
| admin | 所有已建档学生及所有老师 | 镜像仍只能看，管理员原本管理能力只能返回自己的原工作台使用 |
| staff | 不默认开放身份镜像，等待独立授权评审 | 禁止借用staff扩大至所有学生 |

不通过前端角色字段推断权限，必须以服务器真实Session鉴权。严禁在角色切换时换登录token、临时创建学生Session、传学生userId调用其他人的`/me`写API。

## API
- `GET /me/read-only/students/:studentId?stage=...` 初次投影本人学生的 academic profile、当前阶段 classroom view（官方版/待审批学员版）、全部已存课表、成长履历、评估历史、plan revision history。
- `GET /me/read-only/students/:studentId?stage=...&only=classroom` 仅重新授权和读取指定阶段，避免每换一次阶段就加载全量内容。
- `GET /me/read-only/teachers/:teacherId` 只允许 admin，返回老师介绍、归属学员、待审批规划（不可批准）。
- API 没有对应 POST/PUT/DELETE 权限继承路线；尝试伪造目标为普通 `/me/...` 请求只会修改当前登录主体自己的资料，**并不会重定向到被查看学生**。
- 老的公共学生读取路由已经补自有/师生关系/admin授权，否则403；teacher assignment/active状态每次查询，撤销后新请求即时失效。
- 仅显示应展示的业务档案，不返回用户认证token、微信openid、手机号、支付敏感凭据等后台认证字段。

## 微信界面
- 教师从`我的学员`选学生进入镜像；原业务编辑计划功能放在另一个按钮，避免误进入操作模式。
- 管理员`只读切换`栏目列出全部已建档学生及老师，进入后仍保持原管理员账号。
- 学员只读栏目包括“我的资料、我的规划、我的课表、成长记录、AI评估、计划历史”，历史可展开，课表可切换，阶段可切换。无法进入原AI运行/草稿写入、支付等操作页。
- 老师镜像涵盖教师介绍、归属学员、待审规划，可继续点击已分配学生只读查看。
- 不采用只做骨架的镜像，所有内容来自数据库真实记录；无内容时真实空状态。
