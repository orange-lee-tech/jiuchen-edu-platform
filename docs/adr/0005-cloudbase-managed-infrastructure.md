# ADR-0005：V1 采用 CloudBase 优先的托管基础设施

- 状态：Accepted
- 日期：2026-09-17

## 决策

V1 优先使用腾讯 CloudBase 承载线上基础设施：

- 一个 Node.js API 部署到 CloudBase 云托管；
- MySQL 使用托管关系型数据库；
- 文件使用云存储；
- 管理后台使用静态托管或同等简单的托管方式；
- 微信小程序按微信官方流程预览、体验版、审核和发布。

环境只保持三级：**本机 / Test / Production**。Production 在核心业务接近完成后再建立。

## 不做什么

V1 不自行维护 CVM、Nginx、Kubernetes、Redis、ELK、Prometheus、消息队列等基础设施，除非后续出现无法由现有方案解决的真实问题。

## 原因

本项目的目标是可靠和易维护，不需要用基础设施复杂度证明技术能力。托管能力可以减少服务器维护、安全更新、网络配置和部署工作的长期负担。

## 可迁移性

业务逻辑仍写成普通 Node.js 应用；CloudBase 负责托管而不主导领域模型，避免把核心业务写死成大量平台专属函数。
