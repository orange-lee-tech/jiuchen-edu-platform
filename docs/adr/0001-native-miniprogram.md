# ADR-0001：微信端采用原生小程序

- 状态：Accepted
- 日期：2026-09-17

## 背景

产品当前明确只面向微信小程序，需要微信登录、真机调试、后续微信支付等原生能力。项目目标强调可靠、好用、简单，而非跨平台覆盖。

## 决策

V1 微信端采用：

- 微信原生小程序；
- TypeScript；
- TDesign Miniprogram 作为主要 UI 组件来源；
- 微信开发者工具作为官方开发、预览和版本上传工具。

## 不选方案

暂不采用 Taro、uni-app 等跨端框架。

## 原因

- 当前没有明确跨端需求；
- 原生链路最接近微信官方能力；
- 减少框架升级、兼容层和调试复杂度；
- TDesign 已覆盖大量通用 UI，无需大量自造基础组件。

## 何时重新评估

只有在出现明确且持续的支付宝/抖音/H5 等多端业务需求时，才重新评估跨端方案。
