# ADR-0003：生产数据库作为唯一真实状态源

- 状态：Accepted
- 日期：2026-09-17

## 背景

九辰业务数据早期适合使用 XLSX/CSV 等本地文档整理，但小程序需要稳定查询、权限控制、AI 检索、支付记账和后台更新。直接把在线表格、本地 Excel、JSON 文件或 Git 仓库作为生产数据库都会引入一致性和安全问题。

## 决策

生产环境使用正式 SQL 数据库作为业务唯一真实状态源。

本地 XLSX/CSV 仅作为：

- 数据整理；
- 批量导入；
- 人工审阅；
- 必要时的离线备份。

所有进入数据库的数据先经过字段映射和 Schema 校验。

## 原因

- 能建立稳定的数据关系和约束；
- 支持学员数据持续更新；
- 适合 AI 检索与评估历史保存；
- 支持支付额度账本和幂等；
- 避免员工编辑一个表格直接破坏线上系统；
- 后续可迁移而不绑定某个协作文档平台。

## 约束

- 小程序不得直接连接数据库；
- 数据库只能经受控 API/后台访问；
- 真实生产数据不得提交到 Git；
- 数据结构变更使用 migration；
- 导入失败必须提供明确错误，不得静默丢字段。
