# 九辰教育小程序：待集中测试清单

> 目的：开发阶段优先保持模块边界稳定，不要求每完成一个模块就做全链路人工测试。所有需要真实微信、真实数据库、真实服务号权限、多账号/多设备协作或稳定公网出口的验证统一记录在此，后续选择合适窗口集中验收，避免测试条件不足阻断主体开发或引发连锁型误判。

## 1. 使用规则

- 每个模块先通过 CI，再进入本清单等待人工集中测试。
- 当前阶段允许 AUTH / ID / ADMIN 多账号测试以及 NEWS 动态公网 IP 测试后移；TODO 不等于阻塞开发。
- 不为了尽快把清单打勾而临时建立账号密码、假短信、共享测试身份等非生产机制。
- 后续优先用微信开发者工具自动化能力覆盖普通 UI/导航/状态回归；真实多账号只用于必须验证 OpenID、手机号授权和角色隔离的用例。
- 模块测试尽量独立；某模块失败时，不将其自动解释为其它模块失败。
- 测试使用 Test MySQL、测试内部ID、测试微信账号，不写入真实学员敏感数据。
- AppSecret、数据库密码、支付密钥、AI Key 不记录在本文件、不提交 Git。
- 若测试需要修改数据库结构，先执行受控升级脚本；出现 DROP / TRUNCATE / 大量删除时立即停止。
- 每次集中测试后只修改“状态”和“结果记录”，不要删除历史失败原因。
- 状态约定：
  - `TODO`：尚未测试
  - `BLOCKED`：缺少外部条件
  - `PASS`：达到成功条件
  - `FAIL`：未达到成功条件
  - `RETEST`：已修复，等待复测

## 2. 基础设施 / 数据库

### DB-01 Identity V2 Schema 升级
**状态：PASS**

**前置条件**
- 本地 `services/api/.env` 已配置 Test MySQL `DATABASE_URL`
- 本地到 MySQL 的 `/health` 可建立连接

**执行**
```powershell
cd services\api
npm.cmd run db:upgrade:identity-v2
```

**具体要求**
- 脚本必须可重复执行。
- `ECONNRESET / ETIMEDOUT / EPIPE` 等瞬时断线应自动重连重试。
- 不允许因重复执行而重复创建表或破坏已有表。

**成功条件**
- 最终打印 `✓ identity v2 schema is ready`
- `users.status` 存在
- `users.deleted_at` 存在
- `internal_ids` 存在
- `news_posts` 存在
- 重复执行仍成功

**失败条件**
- 连续重试仍 `ECONNRESET`
- SQL 语法错误
- 出现非预期 DROP / TRUNCATE / 数据丢失提示

## 3. 统一登录 / 自动注册

### AUTH-00 登录入口形态
**状态：TODO**

**成功条件**
- 登录页只存在“微信一键登录”和“本机号码登录”。
- 本机号码登录使用微信官方手机号快速验证组件，不要求用户手输短信验证码。
- 不存在账号密码入口、找回密码入口或假短信验证码。
- 两种入口登录后都由服务端业务身份决定游客 / 学员 / 老师 / 管理员界面。

### AUTH-01 微信首次登录自动注册游客
**状态：TODO**

**前置条件**
- 小程序本地调试已切换到本地 API
- `WECHAT_APP_ID` / `WECHAT_APP_SECRET` 已配置

**步骤**
1. 使用此前未登录过的微信身份进入“我的”。
2. 打开统一登录页。
3. 不勾用户协议直接微信登录。
4. 再勾协议完成微信登录。

**成功条件**
- 未勾协议时拒绝登录。
- 首次登录自动创建 User。
- 用户可见身份显示“游客”。
- 不自动分配 JCS / JCT / JCA。
- `user_agreements` 写入当前协议版本。
- `user_sessions` 生成会话。

**失败条件**
- 用户可在登录页自行选择角色。
- 首次登录直接成为 student / teacher / admin。
- 无协议同意记录。

### AUTH-01B 本机号码登录
**状态：TODO**

**成功条件**
- 用户必须主动点击微信手机号快速验证按钮并同意授权；
- 前端将一次性手机号 code 交给服务端；
- 手机号由服务端调用微信官方接口验证取得；
- 首次用户自动创建为游客，不自动分配内部ID；
- 同一微信身份从“微信一键登录”和“本机号码登录”进入时不应产生重复 User；
- 手机号已绑定到另一 User 时不得静默合并账号。
- 用户拒绝手机号授权、手机号能力不可用或平台额度异常时，微信一键登录仍可正常使用。

### AUTH-02 已注册用户再次登录

- 已绑定业务ID时，系统按数据库角色进入对应界面。

### AUTH-03 退出登录
