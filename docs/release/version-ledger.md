## 0.0.19 ZIP 核对（2026-10-19）

用户提供的 `miniprogram.zip` 内有 1510 个文件，包括 1340 个本机 `node_modules` 文件。除本机私有配置外，168 个业务/工程文件与 `main` 的 `apps/miniprogram` blob 完全相同；微信项目配置仅有工具生成的补充字段，AppID 一致。本地 TypeScript 检查与 106/106 回归通过。这是源码核对记录，不是微信平台上传或真机通过的凭证；本机依赖和私有配置不纳入仓库。

## 规则

1. 发布前体验版本沿用 `0.0.x`。此前建议的 `1.0.19` 已作废，不作为本次上传号。首次正式版的编号在商业、真机与审核范围确定后由用户决定；不从体验号自动推断。
2. 每次上传前记录版本号、前端完整 Git SHA、所连 API 完整 SHA、上传时间、微信开发者工具/小程序后台回执；相同版本号不得用于来源不明的另一个源码包。
3. 体验版实际指定、真机验收、提审、审核和正式发布分别登记时间与结果；Git 合并、ECS 切流、开发版预览不替代这些状态。
4. 有阻断修复则生成新的固定源码 SHA，并决定是否递增体验号；历史版本和旧客服聊天卡片不因新上传而改变。
5. 当前 `main` 已整合固定前端与 API，但不把 `main` 的后续文档或 CI 提交误当成新小程序版本。
