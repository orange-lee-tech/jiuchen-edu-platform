# Jiuchen native icons

Original repository-authored square-first line geometry, not downloaded third-party artwork. No external fonts, package or additional license. Generator: `tools/design/generate-miniprogram-icons.cjs`; deterministic 64×64 transparent PNG with 4× antialiasing. Eight native navigation shapes have normal/selected pairs; five functional shapes only have the used active variant. 21 PNG files total, about 10 KB. Native tab paths remain fixed; only text and icon presentation change with validated roles.
